陈 李 我
时长 47 分钟 · 选中你不懂的地方，再点解释

陈：这周我们主要收口一下 Agent 的架构。用户的问题进来之后，先过一个 router 判断意图，需要查资料的走 RAG 这条链路。

具体做法是先用 embedding 把 query 和文档块都转成向量，丢进向量数据库里做召回，取回 top 50 之后再拿 reranker 精排一下，最后只留 5 条塞进上下文。这块上周线上 hallucination 有点多，主要就是召回质量的问题。

李：工具调用这边还是走 function calling，但要注意超时和幂等，同一个请求重试不能重复扣款。

陈：对。另外模型侧这周在做 KV cache 的复用，长上下文的成本能压下来差不多三成。至于 fine-tuning，先不着急，prompt 还没调稳之前别动模型，不然我们连问题是出在数据还是模型上都分不清。
